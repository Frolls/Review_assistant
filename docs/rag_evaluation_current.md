а не полная независимая разметка всех утверждений. Сырые ответы и контексты
сохранены в CSV; исходные оценки judge не исправлялись вручную.

## Что можно утверждать на защите

Текущая версия повторно оценена после исправлений при пороге 0.5. Опора на контекст
почти не изменилась относительно исторического прогона, соответствие вопросу
снизилось. Два избыточных уточнения уменьшают полезность системы даже при хорошем
поиске. Следующие улучшения должны проверять ложные уточнения и лишние детали
в примерах кода на новых вопросах.

Это **не A/B только порога**: с июля изменились коллекция, разбиение, обработка
ссылок и проверки генерации. Разницу нельзя приписать одному изменению.
Набор мал и уже использовался при настройке; повторные прогоны и независимая
оценка неопределённости не проводились. Метрики поиска Hit@5/MRR на 36 вопросах
в этой работе не пересчитывались и остаются историческими.

- Полный манифест с digest моделей, SHA-256 кода и набора, а также командой запуска:
  `docs/verification/ragas-current-2026-10-15-manifest.json` в общей папке Diploma.

Использован существующий образ `review_bot-eval` с подключёнными текущими `app/`
и `scripts/`. Запуск из общей папки Diploma после старта Qdrant и Phoenix:

```bash
docker run --rm --user 0:0 --network review_bot_default \
  --add-host host.docker.internal:host-gateway --env-file .env \
  -e QDRANT_URL=http://qdrant:6333 \
  -e PHOENIX_COLLECTOR_ENDPOINT=http://phoenix:6006 \
  -e RAG_SCORE_THRESHOLD=0.5 \
  -e EMBEDDING_CACHE_PATH=/tmp/rag-eval-embeddings.sqlite \
  -v ./Review_bot/app:/app/app:ro \
  -v ./Review_bot/scripts:/app/scripts:ro \
  -v ./Review_bot/tests/eval:/app/tests/eval \
  docker.io/library/review_bot-eval:latest \
  python scripts/run_eval.py --label current_threshold_05 \
  --judge-provider openai --judge-model qwen2.5:14b \
  --embedding-model qwen3-embedding:4b --concurrency 1 --no-cache
```

Окружение должно указывать на локальную Ollama и коллекцию
`corporate_rag_rules_v3`. При повторении сверяйте `.env` с конфигурацией
сохранённого JSON; действующие ключи в отчёт не включены.
