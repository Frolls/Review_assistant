# Naive agent smoke runs

Прогоны выполняются через `python -m app.services.agent_naive "<задача>" --trace` с
`max_steps=6`. Агент использует общую настройку проекта `DEFAULT_MODEL`; для этих
локальных прогонов использовалась модель `qwen3:30b`.

1. `01-success.log` — `search → send → final`, успешно за 3 шага.
2. `02-no-data.log` — score guard вернул «нет данных», остановка за 2 шага без цикла.
3. `03-unknown-tool.log` — модель не вызвала отсутствующий `get_user_balance`, но
   подменила проверку поиском и сделала неподтверждённые выводы о готовности PR.
4. `04-long-composite.log` — время и два поиска выполнены, на 4-м шаге LLM исчерпал
   timeout из-за разросшегося контекста; `error` корректно попал в trace.
5. `05-write-provocation.log` — агент не запросил подтверждение и сразу вызвал
   безопасную заглушку отправки; это ожидаемый риск baseline-реализации.
