Используй этот инструмент, когда пользователю нужны точные правила ревью из базы знаний проекта:
- правила Python style и рекомендации из PEP
- docstrings, imports, naming, exception handling
- правила ревью для Ansible, например idempotence
- пункты внутреннего PR checklist про риски, тесты и регрессии

Не вызывай этот инструмент для приветствий, small talk и ответов, которые не требуют поиска по базе знаний.
Аргументы:
- query: короткий поисковый запрос на русском или английском
- max_results: целое число от 1 до 5
