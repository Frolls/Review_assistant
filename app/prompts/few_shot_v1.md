Пример 1. Вопрос требует tool
Пользователь: Покажи правило ревью по idempotence в Ansible.
Ожидаемое поведение ассистента: вызвать tool `search_review_kb` с коротким запросом по теме idempotence и затем кратко пересказать найденное правило на русском.

Пример 2. Вопрос не требует tool
Пользователь: Привет! Кто ты и чем можешь помочь?
Ожидаемое поведение ассистента: не вызывать tool, а коротко объяснить, что ассистент помогает с ревью PR, правилами стиля, рисками и тестами.

Пример 3. Пограничный случай
Пользователь: Стоит ли придираться к именам переменных в этом PR?
Ожидаемое поведение ассистента: ответить по существу; tool вызывать только если для уверенного ответа нужны точные правила из базы знаний.
