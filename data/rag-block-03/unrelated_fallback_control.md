# Fallback Control Document

Этот файл намеренно не относится к ревью кода. Он нужен только потому, что в задании требуется один заведомо нерелевантный документ для проверки fallback-сценария.

Документ описывает правила бронирования переговорной комнаты: заявку нужно оставить до 18:00 предыдущего дня, ключ берётся у администратора, а проектор возвращается после занятия.

В этом файле нет информации про Python, Ansible, API, безопасность, миграции базы, тесты, архитектуру, observability или pull request. Если пользователь задаёт вопрос по ревью кода, этот документ не должен быть релевантным источником.

Если пользователь спрашивает тему вне базы знаний, ассистент должен честно сказать, что в корпусе нет достаточной информации, а не придумывать ответ.
